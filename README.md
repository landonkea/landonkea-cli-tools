# landonkea-cli-tools

A collection of Python CLI utilities for everyday tasks.

## Tools

### 1. file-organizer
Organize files by type into folders (Python version).

### 2. disk-usage
Show disk usage for directories.

### 3. batch-rename
Rename multiple files with patterns.

### 4. text-tools
Text processing utilities (word count, line count, etc.).

### 5. system-info
Display system information.

## Installation

```bash
# No installation needed — these are standalone scripts
python file_organizer.py ~/Downloads
python disk_usage.py .
python batch_rename.py "s/old/new/" ~/Photos
python text_tools.py README.md
python system_info.py
```

## Python Version

Requires Python 3.7 or higher.
